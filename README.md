# 🎯 إسألني وبجاوبك - الإصدار 4.0

**نسخة محسّنة وموثوقة** - تم إعادة بنائها بـ Vanilla JavaScript بدون React/Babel.

---

## ⚡ ما الجديد في v4؟

### 🐛 إصلاحات حرجة:
- ❌ **حذف React + Babel Standalone** - كانوا يسببون مشكلة الشاشة الفارغة عند بدء اللعبة
- ✅ **Vanilla JavaScript نقي** - يعمل فوراً بدون أي تأخير في compile
- ✅ يحمّل في أقل من ثانية واحدة (بدلاً من 5-10 ثوانٍ)
- ✅ يعمل بشكل موثوق على GitHub Pages وكل المتصفحات

### 🎨 تحسينات الخط:
- **العناوين:** خط `Lalezar` - عربي حديث وواضح جداً
- **النصوص:** خط `Tajawal` - مقروء وأنيق (من شركة Google Fonts)
- **حجم خط أكبر:** الأسئلة 22px، الإجابات 17px، الأرقام 38-40px
- **سماكة محسّنة:** Bold 700 للنصوص الأساسية

### 🛡️ كود أكثر استقراراً:
- معالجة آمنة للنصوص العربية في الأزرار
- لا توجد أخطاء عند الأسماء التي تحتوي علامات اقتباس
- اختبار شامل لكل الفقرات الـ 7

## 🚀 التشغيل

### محلياً
```bash
cd esalni-v4
python3 -m http.server 8000
# افتح: http://localhost:8000
```

### النشر المجاني (الأسرع)
1. اضغط ZIP على مجلد `esalni-v4`
2. اسحبه إلى [drop.netlify.com](https://drop.netlify.com)
3. ستحصل على رابط فوري

### GitHub Pages
1. أنشئ مستودع جديد
2. ارفع الملفات
3. فعّل GitHub Pages من Settings → Pages

---

## 🖼️ كيف ترفع صورك؟

1. افتح **⚙️ إدارة المحتوى**
2. تبويب **🖼️ الصور**
3. اضغط 📷 بجانب أي عنصر
4. اختر صورة (أقل من 500KB)
5. تُحفظ تلقائياً في المتصفح

## ⚠️ تنبيهات

- **راجع المحتوى** قبل النشر التجاري (خاصة المشاهير، التواريخ، الأرقام)
- **الصور** placeholders (emojis) قابلة للاستبدال
- **localStorage** يحفظ التعديلات محلياً فقط
